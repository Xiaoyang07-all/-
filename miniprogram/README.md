# 豫见中原微信小程序

这是网页平台的原生微信小程序端，页面和接口复用项目根目录的 `server.js`。

## 导入开发者工具

1. 用微信开发者工具导入 `miniprogram/` 目录。
2. 在 `config.js` 中设置服务端地址。开发者工具本机调试可以使用 `http://127.0.0.1:3000`，真机和发布环境必须使用已备案的 HTTPS 域名。
3. 启动网页平台服务：`npm.cmd start`。
4. 在开发者工具中勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”进行本地联调；上线前应把域名加入微信公众平台的 request 合法域名。

## 当前能力

- 首页推荐、目的地横向浏览和中原文化入口
- 景点搜索、分类筛选、详情画廊、地图定位和分享
- 收藏与行程日期保存在当前微信设备的本地存储中
- 景点数据和图片继续读取现有 `/api/spots` 接口

网页端使用邮箱 Cookie 登录，小程序端暂时采用游客模式和本机数据。正式上线时可在 `app.js` 接入 `wx.login`，由服务端把微信用户映射到现有账号体系，再将 `utils/storage.js` 的本地操作替换为收藏和行程接口。
